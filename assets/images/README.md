# PowerCoach Studio – image assets

- **powercoach_logo.png**: Logo con sfondo (usato in app bar e landing).
- **powercoach_icon_foreground.png**: Icona con **sfondo trasparente** per launcher (Android adaptive icon, iOS, Web, Windows, macOS). Solo il simbolo P in gradiente blu–viola; lo sfondo dell’icona è gestito dal sistema (es. `#0D59F2` su Android/Web).
- Dopo aver modificato un’icona, rigenerare le launcher icons: `dart run flutter_launcher_icons`.
