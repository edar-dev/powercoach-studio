Ultimo aggiornamento: 2026-07-09

2. Natura del servizio

PowerCoach Studio è uno strumento di gestione per coach (clienti, piani di allenamento, misure, calendario). I dati operativi del coach sono memorizzati principalmente sul dispositivo o browser dell'utente (architettura local-first). L'autenticazione avviene tramite Supabase.

L'uscita dall'account o la cancellazione dei dati del browser possono rimuovere i dati locali. Esporta regolarmente un backup JSON dalle impostazioni dell'app. Non garantiamo il recupero di dati non sottoposti a backup.
